# 🏠 Airbnb Clone (MERN Stack)

A full-featured Airbnb Clone web application built using the MERN Stack.
Users can explore properties, book stays, and manage listings with role-based access control.

---

## 🚀 Features

### 🔐 Authentication

* JWT-based Login & Signup
* Secure password hashing (bcrypt)

### 🏠 Property Management

* Add / Edit / Delete Properties
* Property details page
* Image support

### 🔍 Property Exploration

* View all properties on Home page
* Clean Airbnb-style UI

### 📅 Booking System

* Book properties with date selection
* Prevent booking own property
* Cancel bookings

### 📊 Dashboard

* 👤 User → View own properties & bookings
* 👑 Admin → View all properties & manage everything

---

## 🛠️ Tech Stack

* **Frontend:** React.js, React Router, Context API
* **Backend:** Node.js, Express.js
* **Database:** MongoDB (Mongoose)
* **Auth:** JWT

## ⚙️ How to Run

### 🔹 Backend

```
cd server
npm install
npm run dev
```

### 🔹 Frontend

```
cd client
npm install
npm run dev
```

---

## 🌐 Access

Frontend: http://localhost:5173
Backend: http://localhost:5000

---

## 🔐 Roles

* **User:** Can book properties & manage own listings
* **Admin:** Full control over all properties & users
